# AUTOSAR specification PDFs

The spec agent chooses a file from the translator output. It does not open every PDF.

Name the file with the document id and the release:

```text
AUTOSAR_TPS_SystemTemplate_20-11.pdf
```

Or put it under a release folder:

```text
20-11/AUTOSAR_TPS_SystemTemplate.pdf
```

Currently only the System Template is expected. Add other documents with the same pattern when they are available.
